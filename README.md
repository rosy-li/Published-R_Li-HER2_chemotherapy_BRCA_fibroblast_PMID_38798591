# HER2+ Breast Cancer — Fibroblast-Mediated Drug Resistance (PMID: 38798591)

> **R code for RNA-seq analysis of 7 HER2+ breast cancer datasets**, supporting the investigation of fibroblast-mediated chemotherapy resistance in the tumor microenvironment.

---

## 📄 About This Repository

This repository contains the R analysis code associated with the following peer-reviewed publication:

**Rational Design of HER2-Targeted Combination Therapies to Reverse Drug Resistance in Fibroblast-Protected HER2+ Breast Cancer Cells**

*Matthew D. Poskus, Jacob McDonald, Matthew Laird, Ruxuan Li, Kyle Norcoss, Ioannis K. Zervantonakis (2024)*

📰 *Cellular and Molecular Bioengineering* — DOI: [10.1007/s12195-024-00823-0](https://doi.org/10.1007/s12195-024-00823-0)

---

## 🧬 Key Findings

This study investigates how breast fibroblasts in the tumor microenvironment promote resistance to HER2-targeted therapy:

- **Fibroblast-conditioned medium** increases expression of PAI1 and cell cycle regulators, counteracting the effects of the HER2 kinase inhibitor **lapatinib**
- **Proteomic profiling** via reverse phase protein arrays identified candidate targets for rational combination therapy
- **Differential expression and multivariate regression modeling** were used to pinpoint actionable resistance mechanisms
- Fibroblast-mediated resistance can be overcome through **rational HER2-targeted combination therapies** informed by systems-level proteomic data

---

## 🗂️ Repository Contents

This repository provides R code for the **RNA-seq analysis of 7 HER2+ breast cancer datasets**, used to validate and extend findings from the in vitro proteomic study. Analyses include:

- Differential gene expression analysis across HER2+ patient cohorts
- Fibroblast gene expression signature scoring
- Survival analysis (overall survival and disease-free survival)
- Pathway enrichment and gene ontology analyses
